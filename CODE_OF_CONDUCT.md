# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community.
Participants should communicate constructively, assume good intent, accept
technical disagreement, and focus criticism on ideas and behavior rather than
people.

Unacceptable behavior includes harassment, discrimination, intimidation,
personal attacks, sexualized language or attention, publishing private
information, and disruptive conduct in project spaces.

## Enforcement

Project maintainers may remove comments, close discussions, restrict
participation, or take other action they consider appropriate after reviewing
a report. Reports should include links, dates, context, and any relevant
screenshots. Please report concerns privately to the project maintainers using
the contact method in [`SECURITY.md`](SECURITY.md); do not create a public
issue for sensitive reports.

This code of conduct applies to project repositories, issue trackers, pull
requests, chat spaces, events, and any other forum where the project community
participates.
